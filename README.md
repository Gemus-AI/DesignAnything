# Design Anything, Design at Scale

This repository will host the public release of **DesignAnything-Bench** and the evaluation materials for the paper *Design Anything, Design at Scale*.

Design Anything is a graph-based harness that keeps a brief's design intent outside the model, so an agent stays on brief across design domains and as projects grow. DesignAnything-Bench contains 228 tasks across 19 design domains, including 38 project families at scales of 6, 14, and 24 artifacts.
