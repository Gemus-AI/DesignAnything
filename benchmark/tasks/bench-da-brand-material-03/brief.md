OPEN WORK DAY | Contributor event identity for two open-source tools

We are bringing PATCHBAY and TYPELOOM together for OPEN WORK DAY at Junction Studio on 17 April 2027, 10:00–16:00. PATCHBAY is an open-source tool for composing reusable data-routing recipes; TYPELOOM is an open-source tool for reviewing type specimens together. The event welcomes contributions to code, design and documentation. Build the event identity around our two supplied complete logos, with the printed event name "OPEN WORK DAY" and invitation "Make one useful contribution."
